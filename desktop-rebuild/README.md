# 破甲桌面端重构框架

本目录是独立的 Tauri 2 + Rust + React + TypeScript 桌面端新框架，与仓库现有 Python 程序并行保留，不覆盖旧版入口或业务文件。

## 开发环境

- Node.js 20+
- Rust stable
- Windows 10/11 WebView2
- Tauri 2 所需 Windows C++ Build Tools

## 启动

在本目录执行：

```powershell
npm install
npm run tauri dev
```

## 构建

```powershell
npm run tauri build
```
